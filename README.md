## 김재근

**AI를 실제 업무 시스템에 붙여, 사람이 믿고 맡길 수 있게 만드는 엔지니어입니다.**

모델이 무엇을 할 수 있는지보다, 그 결과를 누가 어떤 결정에 쓰는지에서 출발합니다.<br>
AI가 틀리거나 멈췄을 때의 동작을 먼저 설계하고,<br>
사람의 승인이 필요한 지점과 실행·비용의 한계를 코드로 명확히 합니다.

---

### Services

- **봄넷** — 농업 필지 분석 및 작물 추천 앱 · [App Store](https://apps.apple.com/kr/app/%EB%B4%84%EB%84%B7/id6761255410)
- **PNU 변환기** — 지번·도로명 주소를 필지고유번호(PNU)로 변환하는 API · [Web](https://pnu.almagest.io/)

### Work

- [**K-Watch**](https://github.com/klolarion/k_watch) — Kubernetes 리소스 간 연결과 Pod 상태 변화를 한눈에 보는 읽기 전용 대시보드
- [**agent_skills / deploy-check**](https://github.com/klolarion/agent_skills) — AI·에이전트 서비스의 배포 준비 상태를 `file:line` 근거로 점검하는 에이전트 스킬

### Now

- 사내 업무 시스템과 연결된 AI 에이전트·RAG 개발 및 운영
- 한국어 소형 LLM 사전학습(Pre-training)
