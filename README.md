## 김재근

**AI를 실제 업무 시스템에 붙여, 사람이 믿고 맡길 수 있게 만드는 엔지니어입니다.**

모델이 무엇을 할 수 있는지보다, 그 결과를 누가 어떤 결정에 쓰는지에서 출발합니다.<br>
AI가 틀리거나 멈췄을 때의 동작을 먼저 설계하고,<br>
사람의 승인이 필요한 지점과 실행·비용의 한계를 코드로 명확히 합니다.

- [PNU 변환기](https://pnu.almagest.io/) — 주소(지번·도로명)를 필지고유번호(PNU)로 바꾸는 API 서비스

**Work**

**Now**
